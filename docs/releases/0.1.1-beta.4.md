# BOAA 0.1.1-beta.4

서버·웹 베타 릴리스입니다. 데스크톱과 Android 설치 파일은 이번 발행에 포함하지 않습니다.

## 주요 변경

- 관리자가 계정을 만들고 초대 링크를 전달할 수 있습니다. 계정별 서재, 읽기 기록, 소스 설정·로그인, 브라우저 저장소를 분리합니다. 확장 설치와 서버 관리는 관리자만 사용할 수 있습니다.
- 일반 듣기에 Supertonic 3와 외부 TTS 엔진을 연결할 수 있습니다. Gemini API, Vertex AI 및 Google Cloud TTS의 서비스 계정 JSON 연결을 지원합니다. 화자 분석 없이 서버 목소리를 선택해 재생합니다.
- 세부 청취 설정에서 문장·문단·묶음 합성 단위를 선택할 수 있습니다. 빈 줄 건너뛰기, 다음 화 첫 음성 준비, 요청 재시도·음성 캐시와 설정 보존을 개선했습니다.
- 발음·문자 필터에서 단어 또는 정규식 교체를 설정하고 `.ttsfilter` 파일을 가져올 수 있습니다. 적용 전 미리보기와 지원하지 않는 규칙 안내를 제공합니다. 원문은 바뀌지 않습니다.
- 장시간 TTS 자동 스크롤 중 본문이 겹치는 문제와 묶음 재생의 문단 따라가기를 보완했습니다. 화면 켜짐 요청과 재생 객체의 수명 관리도 수정했습니다.
- 스트리밍 작품의 회차 다운로드가 작품 표지를 덮어쓰는 문제, 작품·다운로드·휴지통 경계, 최근 읽기 정렬, 모바일 확장 목록과 PWA 설치 정보 갱신을 보완했습니다.

## 기존 설치의 이전

**beta.3에서 이 버전으로는 앱 내 자동 업데이트를 지원하지 않습니다.** 다중 계정 도입으로 DB 호환 경계가 schema epoch 1에서 2로 바뀝니다. 기존 설치는 [오프라인 이전 절차](../../deploy/release-management.md#첫-다중-계정-전환-epoch-1--2-오프라인-이전)를 따라 DB·파일·설정을 함께 백업하고 격리된 새 설치로 이전해야 합니다. 구버전 이미지 하나만 다시 실행하는 방식으로 되돌릴 수 없습니다.

새 설치에는 이 릴리스의 서명된 설치 묶음을 사용합니다. 일반 릴리스 절차는 [서버 관리 문서](../../deploy/release-management.md)를 참고하세요.

## 지원 범위

- 첫 다중 계정 버전에서 회원은 기기 음성을 사용합니다. 서버 AI·유료 TTS와 공유 provider는 관리자 전용입니다. 회원의 개인 서재 내보내기는 지원하지만 복원과 공유 외부 수집기는 제한됩니다.
- 필터는 현재 기기의 계정별 저장소에 저장되며 서버와 동기화되지 않습니다. 정규식은 RE2 호환 범위이며 lookaround와 패턴 역참조는 지원하지 않습니다. 가져오기 화면이 제외할 규칙을 알려 줍니다.
- 묶음 재생의 문단 따라가기는 오디오 진행 시간에 따른 추정입니다. 이어듣기는 묶음 시작에서 재개합니다.
- 모바일 OS의 절전·브라우저 제한까지 해제하지는 않습니다. 실제 Android/iOS의 장시간 화면 꺼짐 재생을 보장하지 않습니다.
- Supertonic 모델은 운영자가 선택 설치하며, 유료 API 이용료는 연결한 계정에 발생합니다. API 할당량 초과 자체를 없애는 기능은 아닙니다.
